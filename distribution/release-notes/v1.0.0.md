First release of Nothing Poweruser Remapper, a power-user remapper for the Nothing Phone's Essential
Key. It is a fork of [EssentialKeyTools](https://github.com/KoukeNeko/EssentialKeyTools) with ideas
from [NothingButtonRemapper](https://github.com/THE-TECH-CHANGER/NothingButtonRemapper).

## Per-app profiles

- Give any app its own single, double, triple and long press actions.
- **Inherit** profiles fall back to the Default profile for gestures they leave unassigned;
  **Isolated** profiles do nothing for them, so presses you did not plan for cannot misfire.
- The profile follows the app you are in, ignoring the notification shade and the keyboard. The lock
  screen uses the Default profile.

## New actions

- Toggle notifications and Toggle Quick Settings (each closes an open shade)
- Launch assistant: opens your default digital assistant directly, e.g. Claude
- Camera: photo (also over the lock screen) and Camera: video
- Camera shutter: presses a camera app's shutter through [Shizuku](https://shizuku.rikka.app/)
- Home screen, Back, Recent apps, Power menu, Volume up and down

## Privacy

To pick a profile, the accessibility service reads which app is in front (package name only). For
the shade toggles it reads the size and type of on-screen windows, so Android warns that it can view
the screen; it never reads what windows show. Nothing is stored or sent. See PRIVACY.md.
